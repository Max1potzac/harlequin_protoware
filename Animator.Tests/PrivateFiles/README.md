# Your own test files

Put your own files here (for example a layered `.psd`) and run the tests in Visual Studio
(Test > Run All Tests). The test `Photoshop_files_of_your_own_come_in_both_ways` reads every
Photoshop file in this folder and brings it in both as a drawn object and with a suggested rig,
checking that every layer arrives where it was.

Everything in this folder except this note is left out of git, so your files stay on your computer.
